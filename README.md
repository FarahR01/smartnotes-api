# SmartNotes API

SmartNotes API is a fast and minimalist REST API for personal note-taking apps.  
It includes authentication (JWT), note CRUD, advanced filters, search, tagging, and a sync endpoint for cross-device updates.

---

## 🚀 Features
- User authentication (JWT)
- Create, update, delete notes
- Search by title
- Filter by tags & archived
- Pagination & sorting
- Sync endpoint for cross-device merging
- Clean modular architecture
- Ready for Docker deployment

---

## 📦 Installation

```bash
git clone https://github.com/YOUR_USERNAME/smartnotes-api.git
cd smartnotes-api
npm install
cp .env.example .env
npm run dev
```

--- 
## 🛠 Tech Stack
- Node.js

- Express

- JWT Authentication

- MongoDB or PostgreSQL (choose later)

- ESLint + Prettier

# *Version Control Best Practices (Tailored to SmartNotes)**

### **Default Branches**
- `main` → always stable & deployable  
- `dev` → active development  
- `feature/*` → each feature (e.g., `feature/auth`, `feature/notes-crud`)
